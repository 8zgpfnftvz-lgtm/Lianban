梯队日线复盘

断板后：
每一列＝当天连板统计里的一个梯队。加载后所有个股使用同一段交易日窗口（断板/所选日前 20 日、后 24 日）， 虚线为所选日，右侧浅色区为之后走势，方便对照「同一节点、不同梯队」后来怎么走。 卡片上的题材/涨停原因来自开盘啦（取该股最后涨停日的分组），悬停可看取数日期、概念和原始行业。 滚动到卡片会自动加载日线（可见优先、加载一张画一张），也可以点「加载全部日线」。 K线来自腾讯行情，首次加载需要联网；加载过的股票会缓存在本机。
怎么找“龙头断板后的中位出清节点”？（按《淘股吧六篇龙头节点体系学习手册》整理）
  1. 只拿 5板及以上、且是当天市场最高板 的高标龙头当锚，普通3、4板断板不算节点。
  2. 龙头最后一天涨停后的第一天没有继续涨停＝首阴断板，节点开始。
  3. 看龙头最后涨停日仍在场的 3板及以上中位票，是否在随后 3个交易日内 批量断板＝中位出清。
  4. 断板当天、次日、第3日出现的 2板 是补涨节点票；第4日及以后出现的2板属于新周期节点。
  5. 次日龙头反包＝退潮延后；反包失败＋中位出清＝旧周期结束，资金寻找新节点。
案例由连板历史自动识别：龙头＝最高连板≥5板、断板当天是市场最高板；中位＝龙头最后涨停日仍在场的3板及以上个股； 若有中位票后来突破前龙头高度，标为节点转移（按手册，它自己的断板才是新节点）。 题材和涨停原因已按开盘啦重标：每个连板段取该股最后涨停日所属的题材组，没有覆盖时退回原行业。 案例标题日期＝龙头最后涨停日，表格里的「实际断板日期」＝下一个未涨停交易日。 节点窗口只统计之后晋级到3板+的2板，不能当作2进3胜率。 每张案例底部可直接核对当日数据来源：打板客网。

口径与说明

数据口径

连板历史：—，共 — 个交易日，只收录 3板及以上 的连板段 （与「天天板」连板统计同口径）。每个连板段记录：代码、名称、所属行业、首板日、最后涨停日、最高板。 数据来自原 index.html 内嵌的 __LIMIT_HISTORY__，抽取时未改动。

题材/涨停原因：按开盘啦「每日涨停原因」接口逐日抓取（GetPlateInfo_w38 / HisLimitResumption）， 覆盖 2025-11-03 至当前数据末日（点「更新数据」会自动扩展）；每个连板段取该股最后涨停日所在的题材组（ZSName）和涨停原因（reason）。 642 段连板全部命中，其中只有 25 段的开盘啦题材与原行业相同。原始行业保留为辅助信息。

点右上角「更新数据」会抓取最新交易日的涨停池和开盘啦题材，结果存在本机；清除后回到原始快照。

安装到桌面（PWA）

这是可安装的 PWA：在 HTTPS 或 localhost 下用 Chrome / Edge / Safari 打开，可以「安装到桌面」， 离线也能打开连板统计、梯队和案例。直接双击 file:// 打开仍然能用，但浏览器不允许 file:// 注册 Service Worker，所以没有安装入口，也不离线缓存。

  • 电脑：双击文件夹里的「启动PWA.bat」→ 浏览器打开 http://localhost:8765/ → 地址栏右侧「安装」或菜单「安装应用」。
  • 安卓：把整个 PWA 文件夹传到 HTTPS 静态站点（GitHub Pages / Cloudflare Pages / Vercel 均可）→ Chrome 打开 → 菜单「安装应用」。
  • iPhone：Safari 打开 HTTPS 地址 → 分享 → 「添加到主屏幕」。
  • 离线只缓存页面本体；日线、涨停池、更新数据仍需要联网。

几个定义

  • 断板日＝最后涨停日的下一个交易日（该股当天没有继续涨停）。
  • 中位＝龙头最后涨停日仍在场的 3板及以上个股（不含当天的其他高标龙头）。
  • 中位出清＝这批中位股全部在断板后 3 个交易日内停止涨停（即最后涨停日 ≤ 断板日 + 3）。
  • 节点票＝断板日、D+1、D+2 当天处于 2板的个股；本数据只保留后来晋级 3板+ 的样本。
  • 反包＝龙头断板后 1～3 个交易日内再次涨停。

日线图

日线为腾讯不复权数据（web.ifzq.gtimg.cn），显示事件当天真实成交价格，通过 <script> 方式加载，不需要服务器； 浏览器直接双击打开本文件即可。首次加载需要联网，之后缓存在 localStorage（约7天）。 若某只票加载失败，卡片会显示「日线加载失败」，可点「重新加载」。

已知限制

  • 连板历史只有 3板+，所以梯队图不含 1板、2板；2板只出现在案例的「节点」列，且是晋级后的样本。
  • 开盘啦题材按“最后涨停日”取，反映的是该段连板末期的炒作理由；同一只票在不同阶段可能换题材。
  • 极少数票在开盘啦当日池里没有记录，会用原行业兜底（会标注行业名）。
  • 本工具只做历史数据整理，不构成任何投资建议。
